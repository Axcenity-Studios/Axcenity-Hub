# Credits audit (2026-11-24)

Whose work Axcenity Engine (at `bf1ca409`) and the Hub are built on, and
what is not yet credited. The engine was only read: nothing in it was
changed. The crate and package lists themselves are generated and shown
on `/credits/` ([../frontend/credits.md](../frontend/credits.md)); this
file records what the lists can't: assets, adapted code, and risks.

## The Hub: nothing missing

- **37 Python packages** (`uv.lock`): all credited with licence, authors
  and home page. Two Windows-only ones (colorama, tzdata) come from
  `credits.PACKAGE_FILLS`.
- **Fonts** (Plus Jakarta Sans, Inter, JetBrains Mono, all OFL-1.1): each
  family's OFL text ships beside it in `static/fonts/` as OFL §2 asks;
  sources in `static/fonts/SOURCES.md`.
- **Tailwind CSS 4.3.5** (MIT): the built stylesheet keeps its licence
  banner. **daisyUI 5.8.2** (MIT) is compiled into the same stylesheet
  without a banner; it is credited on `/credits/`.
- **Everything else** is Axcenity's own: the brand marks, the Toolbox's
  theme (ported from the author's Toolbox), the engine captures and the
  drawn loops.

## The engine: 749 crates

All credited on `/credits/`, from `cargo metadata --all-features`. Some
licences ask for more than a name, and the engine's NOTICE doesn't carry
them yet (NOTICE is what ships with packages and exported games:
`packaging/stage.py:138`, `crates/editor/src/build_game.rs:417`):

| Crate | Licence | Why it matters |
|---|---|---|
| `epaint_default_fonts` 0.36.2 | (MIT OR Apache-2.0) AND OFL-1.1 AND Ubuntu-font-1.0 | egui's default fonts are compiled in (`default_fonts`): Ubuntu-Light (Ubuntu Font Licence), Noto Emoji (OFL), Hack (MIT, Source Foundry Authors), emoji-icon-font (MIT, John Slegers) |
| `egui-phosphor` 0.14.0 | MIT | Bundles the Phosphor icon fonts (MIT); credited only in the About box |
| `symphonia` 0.6.1 (nine crates), `audio_thread_priority`, `triple_buffer` | MPL-2.0 | MPL asks that recipients be told where the source of those files is |
| `webpki-roots` 1.0.11 | CDLA-Permissive-2.0 | Asks for the licence text with the data |
| `unicode-ident` 1.0.27 | (MIT OR Apache-2.0) AND Unicode-3.0 | Ships at runtime (via naga and ron) |
| `rapier3d` 0.36.1, vendored and patched | Apache-2.0 | §4: give the licence and mark changed files (done: `AXCENITY PATCH`); no NOTICE line |

MIT and Apache-2.0 crates also want their licence text with binary
copies; a generated third-party licence file in the packages (for
example by `cargo about`) would cover all 749 at once.
